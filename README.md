# 🎵 Spotify Clone

A responsive **Spotify-inspired music streaming web interface** built from scratch using **HTML and CSS**.

This project focuses on recreating the visual structure and user experience of Spotify's web interface while strengthening my fundamentals in **frontend development, responsive layouts, CSS positioning, Flexbox, and component-style UI organization**.

## 🎯 Project Goal

The goal of this project was to move beyond basic HTML/CSS exercises and build a **complete frontend interface inspired by a real-world product**.

It helped me understand how individual UI elements such as navigation, playlists, cards and a music player can be combined into one cohesive web experience.
